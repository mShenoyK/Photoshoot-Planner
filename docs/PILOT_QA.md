# Controlled pilot acceptance (FC-022)

Automated responsive checks cover 375, 768, 1280 and 1440 px. These are evidence for a pilot candidate, not a claim that photographers have evaluated it or production is ready.

Before inviting clients, complete staging smoke, backup/restore, secret bindings, account recovery and privacy/security review from DEPLOYMENT.md. Start with synthetic/manual profiles and owned source material. Record the exact commit and configuration for each session.

| Scenario                            | Photographer checks                                                                                  |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Individual, indoor artificial       | Useful directions, truthful equipment guidance, original schematic and readable exports              |
| Two-person portrait                 | Exactly two figures and feasible independent support/spacing                                         |
| Four-person mixed family, no photos | Four figures, 3 choices each, coherent palette, lock/swap/hero rebalance, all file formats reopen    |
| Infant/toddler                      | Adult caregiver present in schematic, no balancing/suspension, guardian consent before photos        |
| Stacked monochrome family           | Three-face guide adaptation labeled, key/fill/ambient workflow, coverage/sharpness tested physically |
| Rights withdrawal / provider outage | Invalid sources block new export/download; retry preserves previous files                            |
| Mobile, keyboard, assistive tech    | Tap targets, labels, focus, screen-reader directions, no horizontal overflow, private files reload   |
| Tenant isolation/deletion           | Other shoots/accounts denied; cleanup failure blocks access and can retry                            |

Rate relevance, safety/feasibility, equipment compatibility, diagram clarity, wardrobe comfort/inclusion, explanation quality, source accuracy, export readability and time saved from 1–5. Record consented feedback and specific failed examples; never collect raw client photos for analytics by default. Acceptance requires no unresolved critical safety/privacy defects and a photographer-approved quality threshold chosen before recruiting. Actual participants, satisfaction/adoption metrics, accessibility audit and paid provider fidelity are **not measured** in this environment.
